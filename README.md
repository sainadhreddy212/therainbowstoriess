# Rainbow Stories · therainbowstoriess.com

*for the moments*

The website for **Rainbow Stories**: digital wedding video invitations, save-the-dates, birthday invites, housewarming, baby shower and anniversary invites, caricature invites and wedding websites.

## What's inside

- `index.html`: the complete website in one file (styles, scripts, fonts and logo are built in). Open it in any browser or host it anywhere.

## Highlights

- Opening scene: rain clears, a natural rainbow sweeps from bottom-left to top-right, and the Rainbow Stories name writes itself in the original logo lettering.
- Animated sample invitation designs with filters and previews.
- Wedding website showcase with a live countdown.
- Pricing, FAQ and a contact form that prepares a WhatsApp message.

## Before going live

Open `index.html` and update:

- `WA_NUMBER` near the top of the script: your WhatsApp number, country code first, digits only (e.g. `919876543210`).
- Prices, email address and Instagram handle in the page text.

## Hosting

This repository is published with GitHub Pages. To use the custom domain, add `therainbowstoriess.com` under **Settings → Pages → Custom domain** and point the domain's DNS to GitHub Pages.
